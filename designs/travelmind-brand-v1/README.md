# TravelMindAI 品牌确认稿

确认稿采用青绿淡彩山景、路线M标志、加宽字距与加粗AI。背景等比例显示，保留图片自带的细山路；输入框、推荐按钮及提示小字累计下移50px。

- `index.html`：确认稿静态预览，含色板、动画暂停和本地输入演示。
- `logo-mark.svg`、`logo.svg`：确认后的图标与横排字标。
- `mountains-pastel-reference.png`：用户选定的第三张背景图。
- `_d_meta.json`：确认稿索引。
