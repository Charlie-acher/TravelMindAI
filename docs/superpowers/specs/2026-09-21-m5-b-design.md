# M5-B：文本业务网关与故障降级

承接用户继续开发授权和M5-A适配器。此次把extract/research/review/chat四类文本业务接入同一网关，保留M4工具Agent的DeepSeek原生model属性；plan和周边工具的网关接入另作M5-C，不能据此宣布M5全部完成。

## 决策

复用既有ProviderAdapter和应用生命周期，在app.state保存单进程GatewayState（锁、并发计数、健康窗口），HTTP连接仍按请求关闭。使用配置权重乘最近成功率和延迟因子做加权选择；未明确写进对应能力路由或未配密钥的提供方不参与，不自动发送到其他账号。

每个提供方最多两次尝试，每次调用最多访问四个提供方。超时、连接错误、限流、服务错误可重试一次；JSON外壳/对象错误增加一次格式提醒。400与内容拒绝立即停止，401/403/余额不足不原地重试并禁用该提供方到进程重启。Retry-After超过允许等待时跳过原地重试；窗口/并发/阈值/冷却可配置。一次提供方执行（含重试）的最终失败计熔断，连续三次打开，30秒后仅允许一个半开探测；健康状态跨HTTP请求共用。

成功率/P95来自最近10次提供方执行，统计包含内部重试耗时；并发上限默认每提供方4。满载与熔断时选择其他已授权候选，无候选及时返回503，不排无限队。所有流在首个正文增量后禁止重试/切换；关闭迭代器释放连接和并发名额。业务已有schema/引用修复保留，网关只处理语法层JSON对象校验。

GatewayClient保留generate_json/generate_text/model协议，公开SSE仍只推正文；降级事件仅含from_alias/to_alias/reason_category。知识回答和独立审查通过上下文标记选择research/review；需求和附件抽取默认extract，自然回复chat。管理员状态接口只返回安全统计，不包含密钥、地址、提示词或响应正文。

## 验证

先用模拟HTTP证明主模型503/429/超时→一次重试→备用成功，拒绝/参数错误不切换，流出正文不续写；虚拟时钟验证Open→Half-open→Closed，真实线程验证单探测与并发限制，检查不同客户端共享状态和失败后的名额释放。使用隔离数据库全量回归M4，真实配置仅DeepSeek时只做短文本/JSON/SSE与应用入口验证，不伪称跨提供方真实接通。

无新依赖、无数据库迁移、不修改私人资料归属。默认仍只路由DeepSeek；另三家显式配置与真实验证仍是M5未完成项。配置不变时模型选择不跨提供方。故障注入使用离线传输器，本步不开放生产故障开关。
