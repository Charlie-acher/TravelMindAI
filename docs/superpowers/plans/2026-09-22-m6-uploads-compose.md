# M6上传整链与独立Compose联验

用户要求继续推进，沿用已确认的M6路线。两个独立边界并行实施，最后统一验证：上传测试只写tests/live和验收脚本，主任务负责部署配置和文档。

1. 私人附件：真实页面上传唯一TXT/Markdown→识别→聊天/文件恢复；验证不进入共享库。
2. 管理资料：专用管理员上传唯一内容→解析/切片/索引→聊天来源命中→按编号删除并复查检索；保留其他资料及真实费用。
3. Compose：独立项目的PostgreSQL、etcd、Milvus、迁移、FastAPI、Nginx/Vue；复用backend/.env服务密钥但覆盖容器内数据库/向量地址，独立卷、端口，无现有数据迁移。
4. 验收：先验证配置/镜像和新库迁移，再经Nginx执行真实浏览器链；核对Cookie、SSE、上传及容器重启后持久化。同步03/04/07/08和README，不把配置可解析当作部署成功。

范围：本机单进程部署；不新增集群、多worker健康共享或订票支付。MinerU仍为已部署外部服务，容器通过host.docker.internal访问；明确记录该依赖，不能称OCR也被容器化。

执行记录由主任务在07维护。临时资料仅按本次生成ID和归属清理，数据库/向量/上传持久卷不执行down -v。
