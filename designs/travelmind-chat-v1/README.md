## 设计

- 保留青绿色品牌，使用暖白主界面和淡绿侧栏。
- 用户与管理员均移除右上角“旅行对话”入口。右上角身份切换仅用于查看设计状态，不是正式权限控制。
- 新建对话为居中的品牌、输入框和推荐问题；发送后输入框固定在主区域底部，回复独立滚动。
- 历史对话采用圆角选中态，三点菜单提供重命名和删除确认，支持标题搜索。
- 个人信息位于左下角，姓名允许换行、完整显示。管理员增加共享知识库入口。
- “＋”打开资料选择入口，可显示附件卡片、大小和移除操作。

## 交互范围

对话、名称修改、删除与附件选择只保存在当前页面内存，刷新恢复示例。回复为明确标注的固定示例，不调用智能体。文件不读取正文、不上传、不入库；选择与拖入均限制每条3份，PDF最大30MB，其他文件10MiB，与正式页一致。设计卡片显示“已选择”，点击通过本地文件链接打开；正式页显示真实“已上传”，拖入不自动发送。输入框与发送后使用同款文件卡片，已发送附件位于用户消息气泡上方并右对齐。知识库、退出登录仅展示入口说明，不影响真实账号。

可试用：新建、历史切换、搜索、重命名、删除与取消、推荐问题、Enter 发送、Shift + Enter 换行、Ctrl/Cmd + K 新建、附件选择与移除、账号菜单、身份预览切换、侧栏收起及手机抽屉。

## 文件职责

1. `index.html`：页面结构、图标、菜单和弹窗。
2. `chat.css`：青绿主题、桌面布局、消息滚动区和手机适配。
3. `chat.js`：接收页面操作，修改内存中的示例会话，再刷新侧栏、消息和附件卡片。无后端请求。
4. `logo-mark.svg`：复用已确认的品牌图标。
5. `preview-new-chat.png`、`preview-conversation.png`、`preview-mobile.png`：浏览器实际截图。
