# 对话工作区接入实施计划

用户已确认设计稿并明确要求全部应用现有系统；本计划直接执行，不重复请求方案授权。

目标：将 designs/travelmind-workspace-v2 接入真实会话、私人文件、管理员知识库和运行记录，并支持拖动聊天与右栏的分隔线。

技术：沿用 Vue 3、Arco、FastAPI、SQLAlchemy、PostgreSQL、既有 SSE 与模型网关。不新增前端框架或文件存储系统。

设计依据：docs/superpowers/specs/2026-09-22-chat-workspace-design.md。

- [x] 页面：App.vue、chat.css、ChatIcon.vue、ThinkingProcess.vue；最近历史、新导航、状态/文件面板；拖动分隔线、键盘调整、最小宽度、窗口变化约束及宽度保存。保留当前附件、行程、撤销、停止、恢复行为。验收：前端构建、现有交互回归、桌面及窄屏浏览器。
- [x] 知识库：DocumentPanel.vue、检索测试组件与 api/documents.ts；真实城市计数与分页、列表、上传解析重试、元数据、原文/分段预览和删除；检索测试复用原接口。验收：空结果、筛选、管理员边界与实际命中来源。
- [x] 私人文件：api/personal_files.py、services/personal_files.py、PersonalFilesPanel.vue、api/personalFiles.ts；按归属聚合附件及最新逐日行程，分页、搜索、版本、快照预览和 Markdown 下载。验收：先写接口回归，覆盖其他用户/管理员越权、同名文件、旧预算记录排除和版本独立。

- [x] 状态：usage_events 归属字段和索引、usage.py 的请求上下文、workspace-status 接口；实际型号对应容量，未知值保持 null；最新上下文与累计用量分离。验收：两账号两会话隔离、失败/取消调用、标题调用不覆盖上下文、缓存不重复计数。

- [x] 收尾：迁移、相关后端测试与静态检查、前端回归/构建、数据库/API与浏览器分别验收；docs/07 同步文件职责，docs/08 同步接口、字段字典和实际验收状态。

## 执行约定

页面、知识库和私人文件由互不重叠的任务并行处理，主任务负责标题、统计、过程及最终整合。实施计划中的源文件以现有真实布局为准，运行前保留已有设计改动。Python 命令从 backend 执行，使用 backend/.env；临时文件放 temp 下对应目录。

拖动解释：聊天与右栏之间的垂直分隔线左右拖动，两个区域独立滚动；小屏采用抽屉，不引入自由浮窗拖放框架。

审查重点：旧请求不能回写新账号页面；手动标题不能被模型覆盖；旧行程元信息不能被当前需求污染；失败调用不消失或计作免费；拖动到极限后正文和关闭按钮仍可用。
