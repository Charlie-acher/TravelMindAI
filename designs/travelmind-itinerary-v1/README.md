# TravelMindAI 旅行草稿 · V1

本版为已确认的可交互设计参考。2026-09-20按用户要求移除宣传标题、放大起终点与出行信息，并将布局接入正式Vue行程组件。此静态目录仍使用示例数据；正式程序读取真实会话快照。用户选择三天连续展开，便于整程浏览。

- 视觉：沿用淡绿侧栏、青绿品牌与暖白背景，引用 `frontend/src/chat.css`、`frontend/src/components/ItineraryCard.vue` 及用户提供的长沙三日草稿截图。
- 布局：顶部出发地、目的地、人数、日期及版本；左侧逐日时间线，右侧预算与出发前查询。窄屏将预算移到行程后。
- 交互：按天跳转、地址展开、预算明细展开、查看资料依据示意、路线/天气/调整问题填入输入框、发送演示弹窗、撤销/恢复版本状态。
- 数据：使用截图场景作样例。预算总额3883元、总预算4000元沿用截图，费用分项是设计用演示分配。地点与时间未重新核实。
- 边界：无接口请求；发送不调用模型；地图和来源仅展示入口状态；撤销仅切换演示版本标识，不伪造原始历史行程。正式地图、真实引用及版本内容需在批准接入后复用主程序。

文件：`index.html` 定义布局，`itinerary.css` 定义响应式样式，`itinerary.js` 管理示例数据与页面交互，`logo-mark.svg` 复制自现有品牌。

预览：`http://127.0.0.1:4311/travelmind-itinerary-v1/`。

验证：JS语法检查通过；浏览器1440×1000与390×844查看，手机页面宽度390无横向溢出，三天均保留。预算展开、路线填入、发送演示、撤销恢复和按天跳转通过；控制台未报告警告或错误。此结果仅为设计稿验收，不代表正式后台验收。
